---
name: steeltrack-no-push-github
description: Never commit or push changes to GitHub unless explicitly asked by the user.
metadata:
  type: user
---

Always remember this rule, even when changes are already staged or partially committed locally. The only time pushing is acceptable is when the user directly asks you to push (e.g., "push this change" or "send a PR"). Background servers must be killed and ports confirmed free when done.
